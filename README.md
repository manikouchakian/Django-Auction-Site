Django Auction Site

This project is a simple auction platform built with Django.
Users can create listings, place bids, leave comments, and manage a personal watchlist.

It was originally developed as part of CS50 Web, but I focused on understanding the logic behind each feature instead of just completing the assignment.

⸻

Features

•	Create and manage auction listings

•	Place bids with real-time price updates

•	Comment system for each listing

•	Watchlist functionality for users

•	Close auctions and determine the winner

•	Basic authentication (login, register, logout)

⸻

Tech Stack

•	Python
•	Django
•	SQLite
•	HTML / CSS

⸻

What I focused on

While building this project, I paid attention to:

•	Designing database models and relationships (ForeignKey, ManyToMany)

•	Handling user input and form submissions safely

•	Structuring views in a clear and readable way

•	Keeping the project simple but functional

⸻

How to run the project

    • python manage.py migrate
    • python manage.py runserver

Then open:
http://127.0.0.1:8000/
